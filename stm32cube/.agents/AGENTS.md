
# Development workflow

For every coding task:

1. Inspect the relevant code and understand the existing implementation.
2. Produce a detailed implementation plan before making any changes.
3. Do NOT edit, create, delete, or rename files yet.
4. Do NOT run commands that modify the repository.
5. Wait for explicit user approval.

Only after the user says "OK", "implement", "go ahead", or equivalent:

- implement the approved plan;
- run relevant tests;
- summarize the changes made.

Never skip the approval step.
